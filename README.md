# 🐍 Python – Exercícios Práticos com Estruturas Condicionais

Este repositório reúne atividades desenvolvidas no **Google Colab** com o objetivo de aprofundar os conhecimentos em **estruturas condicionais** utilizando a linguagem Python.

Os exercícios simulam situações do cotidiano, como classificação de números, verificação de números pares e ímpares, avaliação de notas escolares e autenticação de usuários, fortalecendo o raciocínio lógico e a construção de algoritmos.

---

## 🎯 Objetivos do Projeto

* Praticar estruturas condicionais (`if`, `elif` e `else`).
* Desenvolver programas capazes de tomar decisões.
* Aplicar operadores relacionais, lógicos e aritméticos.
* Trabalhar com entrada e validação de dados.
* Resolver problemas utilizando lógica de programação.

---

## 📚 Atividades Desenvolvidas

### 🔹 Atividade 1 – Classificação de Números

Programa que solicita um número ao usuário e identifica se o valor informado é:

* Positivo
* Negativo
* Igual a zero

**Conceitos praticados:**

* Estruturas condicionais
* Operadores relacionais
* Entrada de dados (`input`)
* Conversão para `float`

---

### 🔹 Atividade 2 – Número Par ou Ímpar

Programa que verifica se um número inteiro é par ou ímpar utilizando o operador de resto da divisão (`%`).

**Conceitos praticados:**

* Operador módulo (`%`)
* Estruturas condicionais
* Operadores relacionais
* Entrada de dados

---

### 🔹 Atividade 3 – Situação do Aluno

Programa que recebe a nota de um aluno e informa sua situação acadêmica.

As regras implementadas foram:

* Nota maior ou igual a **7** → Aprovado
* Nota entre **5** e **6,9** → Recuperação
* Nota inferior a **5** → Reprovado

**Conceitos praticados:**

* Estruturas condicionais
* Comparações numéricas
* Regras de decisão
* Entrada de dados

---

### 🔹 Atividade 4 – Sistema de Login

Programa que simula uma autenticação simples de usuário.

O acesso é concedido apenas quando:

* Usuário = `admin`
* Senha = `1234`

Caso contrário, o programa informa que o usuário ou senha são inválidos.

**Conceitos praticados:**

* Comparação de strings
* Comparação de números
* Operador lógico `and`
* Validação de credenciais
* Estruturas condicionais
